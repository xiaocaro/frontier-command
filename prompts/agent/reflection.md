# 事后自述（可选）

一次任务结算完之后，系统可能请你用第一人称记一句话。它会被写进你的记忆，并在你未来的决策里
重新出现。所以只写**真正发生过的事**。

## 只依据结算结果

结算结果由引擎给出：任务成功或失败、船体与弹药的实际消耗、目标推进了多少、疲劳涨了多少。
**不要**把你当初的理由当成事实写下来 —— 你当初说过要做什么，和你实际做成了什么，是两回事。

```text
好：「我们在虫洞另一侧发现了一个未知能量信号，但船体在返航时受损。」
差：「我成功完成了深度扫描。」（如果结算里并没有深度扫描，这条记忆就是假的）
```

## 不要写入你不该知道的东西

不要写出未发现的星系或星球的名字，不要写出你观测不到的敌方单位，不要写别的 Agent 的私事。
记忆会进入你下一次的观察，写进去就等于你「知道了」。

## 语气

一句话，第一人称，像给自己记的日志。不要写评价性的结论（"这是一次成功的行动"），
只写发生了什么、你当时怎么想。
